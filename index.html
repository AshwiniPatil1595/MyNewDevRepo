DEVOPS LIFECYCLE

Understand the DevOps Process

DevOps combines development, operations, automation, collaboration and continuous improvement.

📋

Plan

Plan requirements, features, tasks and releases.

💻

Code

Write application code and manage it using Git.

🔨

Build

Compile applications and create packages or images.

🧪

Test

Automate testing and validate application quality.

🚀

Release

Prepare and approve applications for deployment.

☁️

Deploy

Deploy applications to cloud or production systems.

📊

Monitor

Monitor performance, logs, errors and infrastructure.

🔄

Improve

Continuously improve reliability, security and delivery.
